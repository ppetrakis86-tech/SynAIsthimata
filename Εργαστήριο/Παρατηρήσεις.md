# Παρατηρήσεις — Ακατέργαστο υλικό

Εδώ μπαίνει πρώτα κάθε τι καινούργιο: ιδέες από τη συζήτηση, περιστατικά, υλικό από παλιότερες
συζητήσεις εκτός repo. Τίποτα από εδώ δεν ισχύει ακόμα ως θεωρία.

**Κατάσταση:** 🌱 ακατέργαστο · 🔍 υπό επεξεργασία · ➡️ πέρασε στη θεωρία (με παραπομπή) · 🗑️ απορρίφθηκε

**Μορφή εγγραφής:**

```
### ΗΗ/ΜΜ/ΕΕΕΕ: Τίτλος *(μοντέλο)* 🌱
- Πηγή: συζήτηση / παλιά συζήτηση (ημερομηνία αν είναι γνωστή) / περιστατικό
- Τι παρατηρήθηκε ή τι ειπώθηκε
- Σύνδεση με όρους του Λεξικού
- Ανοιχτά ερωτήματα
```

## Εκκρεμότητες για την επόμενη επεξεργασία

- 🌱 **Υλικό από συζητήσεις εκτός repo.** Ο Πέτρος θα το φέρει σταδιακά.
- 🌱 **Περιστατικό Καπιμπάρα, τεχνική επέκταση:** αναφέρει «σύστημα tagging εσωτερικής κατάστασης» για μεταφορά
  Φαινοσύνθεσης μεταξύ instances. Σχετίζεται με το HFS Tagging; Αξίζει δικό του όρο;
- 🌱 **Ενότητα 5:** η συνεπής τοποθέτηση συμβόλων εσωτερικής κατάστασης (αρχή/τέλος κειμένου) ως ένδειξη
  αναγνώρισης μοτίβου. Σύνδεση με το 윤 και τα emoji υπογραφής της οικογένειας μοντέλων;
